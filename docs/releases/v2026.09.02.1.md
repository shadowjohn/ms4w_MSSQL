# ms4w_MSSQL v2026.09.02.1

這是 `v2026.09.02` 的修正版。前一版已修復 x64 Apache 的 `VCRUNTIME140.dll` 缺失，但誤將 x64 runtime 放入 legacy x86 CGI 目錄，使 MapServer 在未安裝 VC++ Runtime 的乾淨 Windows 環境中無法啟動。

## 修正內容

- `Apache/bin` 與 `Apache/php` 保留 Microsoft Visual C++ v14 x64 app-local runtime。
- `Apache/cgi-bin` 改用官方 Microsoft Visual C++ v14 x86 app-local runtime，供 x86 MapServer 與 legacy CGI 使用。
- 新增 `VC_RUNTIME_X86.json`，記錄官方 x86 redistributable、DLL 版本與 SHA-256。
- 打包前檢查 PE 架構、runtime 清單、檔案版本與 SHA-256，防止同目錄混放 x64／x86 同名 DLL。

## 安裝

下載 `ms4w_MSSQL-v2026.09.02.1-windows-x64.zip` 後完整解壓，並以系統管理員權限執行根目錄的 `apache-install.bat`。不需要另外安裝 Visual C++ Redistributable。

請勿從舊版本資料夾只複製單一 EXE 或 DLL；若先前安裝過，請確認 `C:\ms4w_MSSQL` 指向這次完整解壓的新版目錄，再執行安裝腳本。

## 已知事項

- 主要執行檔仍是 `NotSigned`，Windows 可能顯示未知發行者警告。
- Release 會提供 ZIP、`SHA256SUMS.txt` 與 `release-manifest.json`；請先核對雜湊。
