# ms4w_MSSQL v2026.09.02

這個版本修正可攜式 ZIP 在未安裝 Microsoft Visual C++ Runtime 的 Windows x64 電腦上，啟動 Apache 時出現 `VCRUNTIME140.dll` 缺失的問題。

## 這版修正

- 在 Apache、PHP 與 MapServer 的實際載入目錄提供 app-local Microsoft Visual C++ v14 x64 runtime。
- 以 `VC_RUNTIME_X64.json` 記錄官方 redistributable 套件版本、簽章來源、DLL 版本與 SHA-256。
- 封裝前會從 PE import table 驗證 Apache、PHP、MapServer 仍需 `VCRUNTIME140.dll`，並在執行 EXE 前檢查三個部署目錄的 runtime 完整性。

## 下載與安裝

下載 `ms4w_MSSQL-v2026.09.02-windows-x64.zip` 後完整解壓，不需要另外安裝 Visual C++ Redistributable。請以系統管理員權限執行根目錄的 `apache-install.bat`。

請勿只複製單一 EXE、`Apache/bin` 子目錄或個別 DLL；這會破壞 app-local runtime 的完整性。

## 完整性檢查

`SHA256SUMS.txt` 記錄 ZIP 與 `release-manifest.json` 的 SHA-256。manifest 會額外記錄來源 commit、六個主要執行檔，以及 app-local VC++ runtime 的版本與檔案雜湊。

## 注意事項

- 主要執行檔目前仍是 `NotSigned`，Windows 可能顯示未知發行者警告。
- 此版本驗證 ZIP 結構、app-local runtime、核心版本命令與 Apache service runtime；實際產線網站與個別 CGI 專案仍應依部署環境驗收。
