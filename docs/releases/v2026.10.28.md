# ms4w_MSSQL v2026.10.28

這個版本將 Apache 主程式與標準模組對齊 Apache Lounge 2.4.69 VS18 發行包，並分別修補 Apache/bin 與 PHP 使用的 Brotli。PHP 核心仍為 **8.3.36 x64 TS VS16**；PHP 採兩個 DLL 的 Brotli 1.2.1 overlay，並非完整替換為 PHP 8.3.36-1 重打包版本。

## 更新內容

- Apache/bin 採用 Apache Lounge `httpd-2.4.69-261002-Win64-VS18` 的標準程式與依賴，123 個標準模組按官方包內容對齊；保留額外的 MS4W 模組與 GIS 依賴。模組以官方包及清冊雜湊為準，個別版本字串不一定與主程式相同。
- Apache/bin 的 `brotli.exe`、`brotlicommon.dll`、`brotlidec.dll`、`brotlienc.dll` 採用 Google 官方 1.2.1 Windows x64 dynamic 發行包，並附 `LICENSE.brotli`。
- PHP 僅替換 `brotlicommon.dll` 與 `brotlidec.dll` 至 1.2.1；保留自訂 SQLite 3.54.1、PDO extension loading、RTree、SQLSRV/PDO_SQLSRV 5.12.0、SpatiaLite 及既有設定。
- 新增 `APACHE_RUNTIME.json`，並更新 `PHP_RUNTIME.json` 的實際檔案雜湊與 overlay 來源。原 PHP SBOM 保留為基底清冊，不能把來源重打包內未安裝的 glib、zlib、libzip 更新算入本機 runtime。
- 補齊 Apache 標準包需要的 Lua、HTTP/3、zlib、zstd 依賴與授權檔；HTTP/3 功能仍未實測。
- 發行包逐檔核對兩份 runtime manifest；不包含本機備份、維護路徑、未追蹤資料、OpenSSL 隨機狀態或示範資訊端點。

## 驗證範圍

- 自動檢查：Apache syntax、標準與額外模組載入、Brotli 編碼/解碼、curl HTTPS 與 `br` 解壓、PHP FastCGI、SQLite/PDO/RTree/SpatiaLite，以及 MapServer CGI 初始化；部署後另核對實際載入路徑與雜湊。
- 發行流程：從指定 commit 建立 ZIP，解壓後核對 VC runtime、8 個工具版本與兩份 payload manifest 的逐檔 SHA-256。
- 使用者手動驗收：確認 PHP 可執行、CGI 正常出圖、easymap_server 正常。私人驗收截圖不隨發行包公開。
- 未測項目：實際 MSSQL 資料庫連線、HTTP/3 連線，以及漏洞專用 PoC。SQLSRV/PDO_SQLSRV 僅完成模組載入檢查。
- 主要執行檔與自訂 SQLite extensions 仍依實際狀態標記為 `NotSigned`，不宣稱已具 Authenticode 簽章。

## 正式機更新與回復

1. 下載 `ms4w_MSSQL-v2026.10.28-windows-x64.zip`、`SHA256SUMS.txt` 與 `release-manifest.json`，先驗證雜湊，再解壓到獨立目錄。此發行不會自動連線或部署到正式機。
2. 完整備份正式機目前的 Apache/bin、modules、PHP、兩份 runtime manifest、Apache 設定、php.ini、憑證與自訂擴充，保留原檔案權限及使用者資料。核對正式機的版本與 PHP ABI；若 PHP 尚非 8.3.36，先依 [PHP 升級指南](https://github.com/shadowjohn/ms4w_MSSQL/blob/v2026.10.28/docs/php-8.3.36-upgrade.md) 處理完整 runtime 升級，不能把兩個 Brotli DLL 當成完整 PHP 升級。
3. 依正式機實際部署，找出使用目標檔案的 Apache、PHP worker、CLI 工作與可能共用 PHP 的 IIS app pool。只暫停相關使用者，確認檔案已釋放；不要套用其他主機的服務名稱或路徑。
4. 依 `APACHE_RUNTIME.json` 同步標準 bin/modules 與 Brotli overlay；額外 MS4W/GIS 模組與依賴保留。PHP 已在同一 8.3.36 基底時，只套用兩個 Brotli DLL 與對應 metadata。不要把三個目錄整包硬蓋：保留正式機 php.ini、Apache 設定、憑證、自訂 SQLite/SQLSRV、SpatiaLite 與資料。
5. 核對實際檔案 SHA-256、`httpd -t`、模組載入、`curl --version` 與 PHP `curl_version()` 的 Brotli 1.2.1；`php -v` 仍為 8.3.36，不能單獨證明修補完成。只恢復原本運行的相關服務，並驗收 PHP、CGI 出圖、easymap_server、SQLite/GIS 與正式資料庫功能。
6. 若失敗，停止本次變更的相關使用者，成套還原備份檔案與 manifest，確認沒有混版後再恢復原服務；不要覆蓋、回滾或刪除業務資料。

發行包未包含網站私有設定與應用資料，仍需由各正式環境自行保留與驗收。
