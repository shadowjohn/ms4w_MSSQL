# ms4w_MSSQL v2026.11.13

本版更新 Apache 至 **2.4.71 Win64 VS18**，修補最新 HTTP/2 安全漏洞，並同步更新 PHP Windows **8.3.36-1**、Apache 額外模組與隨附的 Microsoft VC runtime。既有設定、SQLSRV 及 SQLite／SpatiaLite GIS 支援保留。

## 安全與元件更新

- Apache 2.4.69 → 2.4.71，包含 CVE-2026-119618（mod_http2 記憶體破壞／RCE）、CVE-2026-106023（mod_md crash）及 CVE-2026-109163（mod_vhost_alias stack overwrite）修補。[Apache 官方公告](https://httpd.apache.org/security/vulnerabilities_24.html)
- Apache 包同步提供 curl 8.23.0、nghttp2 1.71.0、zlib 1.4、nghttp3 1.19.0、ngtcp2 1.26.0、APR-util 1.6.6 與 Expat 2.10.0；OpenSSL 3.5.9、Brotli 1.2.1 維持原版本。新增必要的 `Apache/bin/libz.dll`。[Apache Lounge changelog](https://www.apachelounge.com/Changelog-2.4.html)
- PHP 改用官方 Windows 8.3.36-1 TS x64 VS16 重建包，補齊 glib 2.90.1、libzip 1.12.1 與 zlib 安全回補；Brotli 1.2.1 已由新基底原生提供。`php -v` 仍顯示 8.3.36，應搭配清冊與 DLL 雜湊核對重建版本。[官方 PHP SBOM](https://downloads.php.net/~windows/releases/php-8.3.36-1-Win32-vs16-x64.zip.spdx.json)
- ModSecurity 2.7.0-rc2 → 2.9.15，補齊 `bin/yajl.dll`；mod_fcgid 更新為 2.3.10 VS18 build，mod_xsendfile 更新為 1.0-P1 VS18。沿用既有啟用狀態，沒有因此自動啟用 WAF 或其他模組。
- app-local VC runtime 14.51.36247.0 → **14.52.37029.0**。x64 DLL 位於 `Apache/bin`、`Apache/php`，x86 DLL 位於 `Apache/cgi-bin`；維持免另裝 redistributable 的部署方式。
- 同步更新四份 runtime JSON、元件來源與授權聲明。官方 Apache ZIP、PHP ZIP 及 Microsoft VC 來源均已核對來源完整性；Apache Lounge 額外模組僅有 HTTPS 來源與本地計算的 SHA-256，未宣稱另有供應商簽章驗證。

## 既有主機更新

**本次不只更新 Apache/bin 與 Apache/modules。** 完整範圍包括：

1. `Apache/bin`、`Apache/modules` 的更新檔案，包含新增的 `libz.dll`、`yajl.dll`。
2. `Apache/php` 的 PHP payload 與三個 x64 VC DLL，包含有變更的 `ext`、`extras/sbom` 等子目錄。
3. `Apache/cgi-bin` 的 `vcruntime140.dll`、`msvcp140.dll` 兩個 x86 VC DLL。
4. `APACHE_RUNTIME.json`、`PHP_RUNTIME.json`、`VC_RUNTIME_X64.json`、`VC_RUNTIME_X86.json` 與 Apache／額外模組授權文件。

更新前先備份，停止對應 Apache、IIS 集區、共用 PHP 的測試站與背景排程，確認 DLL 已釋放再替換。不要以鏡像同步刪除額外 GIS DLL，也不要用官方 PHP ZIP 直接蓋掉自製 SQLite extensions。保留目標主機的 `httpd.conf`、`php.ini`、憑證、站台資料、SQLSRV 與 GIS 依賴。詳細步驟及來源 hash 見 [更新及上架清單](../apache-2.4.71-php-refresh.md)。

差異檔案僅適合原本已在 v2026.11.05 基線的主機；較舊或另有客製的主機應先比對清冊及 ABI。GitHub Release ZIP 為完整 runtime 套件，仍需保留各主機自己的設定。

## 驗證與限制

- 本機 runtime 8/8、隔離 Web 16/16、記憶體 GIS 27/27 通過；279 個 Apache／PHP／VC 清冊項目 SHA-256 符合，35 個設定／客製／既存未追蹤檔保持原 hash。
- Web 驗證涵蓋 TLS HTTP/2 協商、平行請求、Brotli 解壓、PHP FastCGI、SQLite RTree、PDO SpatiaLite、SQLSRV 載入、MapServer CGI 初始化、ModSecurity 放行／阻擋、X-Sendfile 與 404。SQLSRV 載入測試沒有連線實際資料庫。
- 發行封裝使用指定 commit 的 tracked 檔案，解壓後再檢查 8 個工具、VC runtime、Apache/PHP 清冊與既有 CGI 清理規則；不納入本機未追蹤 DLL、私有站台或測試證據。
- 自製 SQLite 3.54.1、SpatiaLite 5.1.0 與 SQLSRV 5.12.0 保留。SQLSRV 新分支與舊 Python／GDAL／MapServer 的整套升級，需另外評估相容性及實際資料回歸。
- Apache Lounge 本版 curl 不再支援 SMB／SMBS；使用 `curl smb://...` 的腳本需要另行調整。舊 GIS 相依 DLL 沒有因此被移除。
- 沒有執行 CVE exploit PoC，也未驗收其他主機、IIS、真實 MSSQL 或 production 流程。實際漏洞暴露面仍取決於各主機啟用的模組與設定。
- 主要 Apache/PHP 執行檔與自製 SQLite extensions 維持 `NotSigned`。請核對 `SHA256SUMS.txt`；`release-manifest.json` 記錄來源 commit、檔案大小與 runtime 雜湊。
