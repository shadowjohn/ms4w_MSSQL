# ms4w_MSSQL v2026.10.22

這個版本整合 PHP 8.3.36 安全更新、SQLite GIS 功能與 Apache 服務批次檔修正，也收錄前次 Release 後的 HTTPS 憑證與 SHP 空間索引工具修正。

## 更新內容

- PHP／Zend OPcache 升級至 8.3.36 x64 TS VS16，整套更新官方 Windows runtime 與配套 DLL。
- 以 PHP 8.3.36 原始碼重建 `php_pdo_sqlite.dll` 與 `php_sqlite3.dll`，靜態連結 SQLite 3.54.1，保留 PDO `load_extension()`、SpatiaLite 5.1.0 與 RTree。SQLSRV／PDO_SQLSRV 保留 5.12.0。
- 新增 `PHP_RUNTIME.json`，記錄官方來源與部署檔 SHA-256，並在 repository 提供 SQLite extensions 的重建腳本。
- 修正三支 Apache batch 的管理員檢查，不再依賴 Windows「Server」服務；該服務停用時，仍可按右鍵「以系統管理員身分執行」。
- 安裝、重啟、移除結束後保留視窗顯示結果；命令列或自動化可加 `/nopause`，退出碼會保留。
- 補回 PHP HTTPS／cURL 使用的 `cacert.pem`。
- 修正 `shptree.exe` 的 DLL 參照，使用此工具包的 `libmap.dll`，避免啟動時出現進入點錯誤。

## 安裝與更新

下載 `ms4w_MSSQL-v2026.10.22-windows-x64.zip` 後先核對 `SHA256SUMS.txt`，再完整解壓。可放在 `D:\mytools\ms4w_MSSQL` 或 `D:\tools\ms4w_MSSQL`，並在外層 `apache-install.bat` 按右鍵「以系統管理員身分執行」。

首次安裝會建立 `C:\ms4w_MSSQL` 連結。既有連結與 runtime 會保留；若先前安裝過，請先確認 `C:\ms4w_MSSQL` 指向這次完整解壓的新版內層 `ms4w_MSSQL` 目錄。更新前備份原本的 PHP／Apache 設定與站台資料，確認相關程序已停止使用目標 DLL 後，再依 [PHP 升級說明](https://github.com/shadowjohn/ms4w_MSSQL/blob/v2026.10.22/docs/php-8.3.36-upgrade.md) 更新。

套件內含 x64／x86 各自所需的 app-local Microsoft Visual C++ runtime，不需要另外安裝 Redistributable。請完整使用工具包，避免單獨替換 EXE 或 DLL。

## 驗證與已知事項

- 發布流程會在打包前與解壓後檢查六個核心工具的版本，以及 app-local VC runtime 的架構、版本與 SHA-256。
- 批次檔隔離模擬通過 17/17；實際以管理員執行安裝、重啟與移除仍待驗收。
- PHP 升級記錄已驗證 CLI 與 Apache FastCGI 的 SQLite／PDO CRUD、RTree、SpatiaLite 幾何與空間索引操作；實際 MSSQL 連線、應用程式資料及其他主機仍需個別驗收。
- 舊 PHP 5.3.2 legacy CGI 保留原有版本，這次 PHP 主 runtime 升級不涵蓋其修補。
- 主要執行檔與自訂 SQLite extensions 仍為 `NotSigned`，Windows 可能顯示未知發行者警告。
- Release 提供 ZIP、`SHA256SUMS.txt` 與 `release-manifest.json`。官方 PHP SBOM 對應上游 ZIP；自訂 SQLite extensions 的來源與實際檔案雜湊以 `PHP_RUNTIME.json` 為準。
