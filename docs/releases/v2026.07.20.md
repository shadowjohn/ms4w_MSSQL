# ms4w_MSSQL v2026.07.20

這是第一個可直接下載的 Windows runtime 快照，內容對應 2026-07-20 的 `main`。基底仍是 MS4W 4.0.4，這次主要整理 Apache 2.4.68、PHP 8.3.32，以及既有的 GDAL、MapServer、Python、SQLite／SpatiaLite 工具。

## 這版包含

- Apache 2.4.68 與 PHP 8.3.32 x64 runtime
- MapServer 7.7.0-dev、GDAL 2.4.0、Python 3.7.8
- SQLite 3.42.0 與 SpatiaLite 相關 DLL
- 安裝、重啟與移除 Apache service 的 batch 檔

## 下載與安裝

下載 `ms4w_MSSQL-v2026.07.20-windows-x64.zip` 後完整解壓，不要只取出單一 EXE 或 DLL。接著以系統管理員權限執行根目錄的 `apache-install.bat`。

安裝腳本會使用固定位置：

```text
C:\ms4w_MSSQL
C:\sqlite3_ext
```

## 完整性檢查

`SHA256SUMS.txt` 同時記錄 ZIP 與 `release-manifest.json` 的 SHA-256。下載後可用 PowerShell 核對：

```powershell
Get-FileHash .\ms4w_MSSQL-v2026.07.20-windows-x64.zip -Algorithm SHA256
```

`release-manifest.json` 另外記錄來源 commit、檔案大小，以及六個主要執行檔的版本、SHA-256 與 Authenticode 狀態。

## 注意事項

- 主要執行檔目前都是 `NotSigned`，Windows 可能顯示未知發行者警告。
- 這套環境適合開發與既有 GIS 產線，不建議未調整安全設定就直接對外公開。
- 套件保留多個舊版相依元件；升級前請先用實際 Easymap、MapServer、GDAL 與 SQLite 流程驗證相容性。
