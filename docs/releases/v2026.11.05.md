# ms4w_MSSQL v2026.11.05

這個版本預設停用未使用的 PHP Session 上傳進度追蹤，並整理 `Apache/cgi-bin`：移除舊 PHP 5／7 runtime、建置產生器與測試範例，提供可複製到其他主機執行的清理批次檔。

主 runtime 維持 **Apache 2.4.69、PHP 8.3.36 x64 TS VS16，Brotli 1.2.1 overlay**，既有 SQLite 3.54.1、RTree、PDO extension loading、SpatiaLite 與 SQLSRV 支援保留。

## 更新內容

- 主 `Apache/php/php.ini` 設定 **`session.upload_progress.enabled = Off`**，停用目前未使用的 Session 上傳進度追蹤。這個設定不會關閉一般 Session 或檔案上傳；指令說明見 [PHP 官方文件](https://www.php.net/manual/en/session.configuration.php#ini.session.upload-progress.enabled)。
- `httpd.conf` 的主 PHP FastCGI 區塊增加 Start／End 註解，標示不需要 PHP 時可調整的範圍；PHP handler 仍指向 `Apache/php/php-cgi.exe`。
- 移除 CGI 目錄的 17 個舊 PHP 專用檔案，包含執行檔、設定、PHP 5 module／DLL 與 PHP 7 DLL／import library。
- 移除 8 個建置／測試檔案：SQLite 與 Protocol Buffers 產生器、OWT GIF sample、`printenv.pl`、`test.png`。
- 新增 `Apache/cgi-bin/remove_cgibin_useless.bat`。以批次檔所在位置清理固定的 25 個檔名，不遞迴、不建立備份、不停止服務。支援 `/dry-run`、`/nopause`，可重複執行。
- 清理前確認旁邊有 `mapserv.exe`，且主 PHP FastCGI 存在；`printenv.pl`、`test.png` 只有符合已知樣本 SHA-256 才會刪除，修改過的樣本保留。
- 新增 CGI 盤點文件，以精確 `.gitignore` 規則避免退役檔案、本機備份、cache 與私有站台資料誤入新追蹤。不廣泛忽略 DLL 或 EXE。
- 保留 MapServer／GIS 工具、共用 DLL、MapCache、TinyOWS、PDAL、MapScript、OWTChart 與站台資料。

## 既有主機更新

清理批次檔只移除舊檔案，不會修改主 PHP 設定。若沿用既有 `php.ini`，請在 `Apache/php/php.ini` 同步設定：

```ini
session.upload_progress.enabled = Off
```

讓對應的 PHP FastCGI／Apache 程序重新載入設定後，再確認實際生效值。下載新版 ZIP 不等於其他主機的現役設定已更新。

將 `remove_cgibin_useless.bat` 放入該主機的 `Apache/cgi-bin` 目錄內，先預覽：

```bat
remove_cgibin_useless.bat /dry-run /nopause
```

確認清單後執行 `remove_cgibin_useless.bat`。它會直接刪除固定清單內的檔案，不存在的項目會跳過。若另外使用 CGI 目錄中的 Protocol Buffers compiler，請先調整固定清單；其他目錄的同名工具不受影響。

## 驗證與邊界

- 清理 BAT 的隔離 fixtures 通過 12/12，包含精確清單、保留 GIS／共用 DLL、預覽、錯誤目錄、CGI 環境拒絕、樣本雜湊、重複執行、唯讀檔案失敗及退出碼。
- 使用者已在本機執行清理工具；固定清單的 25 個路徑均已移除。
- 發行驗證從指定 commit 建立 ZIP，解壓後檢查 8 個工具、VC runtime、PHP／Apache payload manifests，並核對舊 CGI 檔案缺席、清理 BAT 存在與 PHP 實際讀到 `upload_progress` 停用值。
- 其他主機的 PHP／Apache 重新載入、應用程式流程、地圖出圖、真實 MSSQL 連線與 HTTP/3 仍需各主機驗收；不宣稱已完成特定漏洞 PoC 驗證。
- 主要執行檔與自訂 SQLite extensions 維持實際的 `NotSigned` 狀態。請核對 `SHA256SUMS.txt`；`release-manifest.json` 記錄來源 commit、檔案大小與 runtime 雜湊。
